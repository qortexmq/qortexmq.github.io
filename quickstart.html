🚀 Быстрый старт

Запусти сервер и используй .NET клиент для отправки и получения сообщений:

dotnet@localhost:~
$ docker run -d --name qortexmq-server -p 9090:9090 -p 9080:9080 qortexmq-server
$ # Открыть http://localhost:9080 для веб-интерфейса

Теперь используй .NET клиент для отправки сообщений:

Publisher.cs
using QortexMQ;
using QortexMQ.Common.Enums;

// Создаём клиент с современным API
using var client = new QortexMqClient("127.0.0.1", 9090);
await client.ConnectAsync();
// Отправляем сообщение с высоким приоритетом
await client.PublishAsync("orders", "Новый заказ #123", MessagePriority.High);

И подпишись на топик для получения сообщений:

Subscriber.cs
// Подписываемся на топик с обработчиком
await client.SubscribeAsync<string>("orders", async (message) =>
{
Console.WriteLine($"Получен заказ: {message}");
await Task.Delay(100); // Обработка
}, maxHandlers: 1); // 1 параллельный обработчик
